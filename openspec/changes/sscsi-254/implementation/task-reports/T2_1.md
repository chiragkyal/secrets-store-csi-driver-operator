## Summary

Implemented `ResolveSecretsStoreConfig(spec *opv1.ClusterCSIDriverSpec) (ResolvedRotationConfig, ResolvedTokenRequestsConfig)` in a new file, `pkg/operator/secretsstoreconfig.go` — the single shared read/resolve helper that both the future `CSIDriver` `AssetFunc` (T3_1/T3_2) and the `DaemonSetHookFunc` (T4_1) will call. Confirmed directly from the vendored API types that every nested level of `CSIDriverConfigSpec.SecretsStore` is a value type with `omitzero` (not a pointer as the EP/plan assumed), simplifying the implementation to discriminator-string comparisons with no nil-pointer risk. Added a 10-case smoke test suite; `go build`, `go vet`, `make verify`, and `make test-unit` all pass cleanly.
