## Deviations

- **Task T1_2**: The task payload's Target file(s) list (`go.mod`, `go.sum`, `vendor/modules.txt`, and the single `types_csi_cluster_driver.go` file) did not anticipate that `openshift/api` cannot be bumped in isolation — `openshift/client-go` and `openshift/library-go` must be bumped in lockstep, since OpenShift releases these three repositories together and their vendored code cross-references each other's types. This is a **process deviation** worth carrying forward to future tasks/changes in this repo: any future `openshift/api` bump task should default to bumping all three `openshift/*` dependencies together rather than just the one referenced in a spec/EP.
